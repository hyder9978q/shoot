# سحب الأماكن الرياضية من خرائط Google

خط من خطوتين: نسحب الأماكن لملف، ونزرعها بـ Firestore.

## ١. السحب

```bash
node tool/fetch_places.js --key=AIza...
```

يبحث بـ ١٧ مدينة عراقية × ١١ نوع مكان (ملاعب خماسية، بادل، تنس، سلة، طائرة،
مسابح، أندية رياضية، مجمعات) → `tool/places.json`.

المفتاح لازم يكون **بدون قيد IP** (أو IP جهازك مضاف بالسماح)، ومفعّل عليه
`Places API (New)`. مفتاح WebCraft الحالي مقيّد بـ IP الخادم `204.168.207.20`.

## ٢. الزرع بـ Firestore

```bash
node tool/seed_firestore.js --sa=serviceAccount.json --dry   # تجربة بدون كتابة
node tool/seed_firestore.js --sa=serviceAccount.json         # كتابة فعلية
```

حساب الخدمة: Firebase Console → Project Settings → Service Accounts →
Generate new private key. (مضاف بـ `.gitignore` — لا تحطه بالمستودع.)

معرّف المستند = `placeId`، فإعادة التشغيل **تحدّث** المكان بدل ما تكرره،
و`merge: true` تحافظ على اللي حدده صاحب الملعب (السعر، الوصف، المرافق، الدوام).

## ٣. مفتاح التطبيق

الصور تنجلب وقت العرض، فالتطبيق يحتاج مفتاحه الخاص:

```bash
flutter run   --dart-define=GOOGLE_MAPS_KEY=AIza...
flutter build web --dart-define=GOOGLE_MAPS_KEY=AIza...
```

هذا **مفتاح ثاني** غير مفتاح السحب: مقيّد بالتطبيق (اسم الحزمة + SHA للأندرويد،
ونطاق الموقع للويب) ومحصور بـ `Places API (New)`. بدون مفتاح، التطبيق يرجع
للرسمة المرسومة تلقائياً بدل ما ينكسر.

## ملاحظات ترخيص Google

- نخزن **معرّف المكان ومرجع الصورة** فقط — مو الصورة نفسها. الصورة تنجلب من
  Google وقت عرضها بالتطبيق.
- محتوى الأماكن (غير معرّف المكان) ما ينخزن أكثر من ٣٠ يوم → شغّل السحب
  شهرياً حتى تتجدد المراجع والتقييمات.

## الأماكن المسحوبة ما عدها سعر

Google ما تنطي أسعار، فـ `pricePerHour = 0` والتطبيق يعرض **"اتصل للسعر"** مع
رقم هاتف المكان. لما صاحب المكان يسجّل ويحدد سعره، يصير قابل للحجز داخل
التطبيق (`isBookable`).
